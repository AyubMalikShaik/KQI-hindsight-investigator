What already works (do not rebuild)
Evidence engine
Tools return compact Evidence with ChartSpec. Driver decomposition (volume vs rate) lives in tools/sql.py. ToolCallGuard repairs JSON, caches, and stops repeat loops.

Memory as prior, not truth
Recall twice (signature then evidence). Priors attach per mechanism. Stage-2 feedback replaces the same document_id. Reflect is written to disk and not re-retained.
